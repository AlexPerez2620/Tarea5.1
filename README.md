Proyecto: Página web responsiva utilizando Bootstrap y CSS

El objetivo de este proyecto es crear una página web.
adaptable mediante el uso de CSS, Bootstrap y HTML.

El sitio tiene una página de inicio, así como otra de
una página de contacto y un portafolio.

Una barra de navegación se incluye en la página principal.
una sección sobre, un encabezado con una imagen de fondo
del dueño y botones para navegar.

El portafolio emplea tarjetas de Bootstrap para presentar
proyectos imaginarios con vínculos a páginas de información detallada.

La página de contacto tiene un formulario que contiene campos
para el correo electrónico, el nombre y el mensaje, así como también
validación con Bootstrap.

El diseño se personalizó usando CSS y se ajustó.
para ordenadores de sobremesa y dispositivos móviles.
