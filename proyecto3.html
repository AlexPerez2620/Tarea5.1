Blog tecnológico

Este proyecto representa un blog tecnológico ficticio dedicado a noticias y tendencias relacionadas con computadoras y tecnología.

El sitio organiza los artículos utilizando una estructura sencilla y moderna creada con HTML, CSS y Bootstrap.

El diseño responsivo permite que los artículos puedan visualizarse correctamente desde diferentes tamaños de pantalla.
